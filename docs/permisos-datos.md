# Fuentes y permisos de reutilización

La licencia MIT cubre el código original del atlas. El Excel, el CSV, las bases SQLite, las exportaciones, las capas geográficas y las imágenes reúnen materiales de diversa procedencia. El proyecto no otorga una licencia conjunta para redistribuir esos materiales. Los permisos dependen del contenido que se reutilice y de su fuente.

## Cómo comprobar la procedencia

En el consolidado, consulta **ID de fuente** y **Referencia directa** para identificar el documento que describe el desfile. Para reutilizar su ubicación, revisa también **Proveedor / fuente de coordenadas** y **Método / precisión**. Una fila puede tomar la programación de una portaria y el punto geográfico de otro proveedor. La hoja **Fuentes** del Excel y el historial de correcciones permiten seguir esa distinción. [Metodología y referencias por edición](../LEEME_fuentes_y_formato.txt)

| Fuente o material | Qué tener en cuenta al compartirlo |
| --- | --- |
| OpenStreetMap, incluidos los registros que citan Photon o Nominatim sobre datos de OSM | Atribuye los datos a © OpenStreetMap contributors e identifica la ODbL 1.0. Si distribuyes una base derivada de OSM, revisa las obligaciones de compartir bajo la misma licencia. Para un mapa o una captura, conserva la atribución visible. [Atribución](https://www.openstreetmap.org/copyright) · [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) |
| G1, agendas y otras publicaciones | La referencia identifica la publicación consultada. El proyecto no ha acreditado una autorización general para redistribuir sus textos, extractos o conjuntos de datos. Comprueba los términos del editor para el material que quieras reproducir. |
| Prefeitura de São Paulo, CarnavalSP, CET y GeoSampa | Identifica la portaria, el anexo o la capa concreta. Conserva el organismo, el documento y, para cartografía, la fecha de la capa. Verifica las condiciones de esa publicación, especialmente si vas a distribuir geometrías de recorridos o límites administrativos. |
| Google Maps y otras referencias de direcciones o CEP | Comprueba si el proveedor aportó una coordenada o sirvió para contrastar una dirección. El proyecto no concede derechos sobre contenido de Google. Sus condiciones limitan la copia y la redistribución. [Condiciones de Google Maps](https://www.google.com/help/terms_maps/) |
| Revisión manual, transferencias históricas y puntos heredados | Conserva la referencia original junto a la corrección y su precisión. En 17 registros el método original quedó sin documentar. Si necesitas acreditar el derecho a redistribuir uno de esos puntos, verifica su origen antes de incluirlo. |

Al publicar resultados, identifica la versión del atlas utilizada y conserva las referencias de los registros o capas que sustentan tu análisis. Para una consulta o corrección, indica el año, el ID de fuente y el campo correspondiente. [Consultas del repositorio](https://github.com/josebravof99/blocos-de-rua-datos/issues)
